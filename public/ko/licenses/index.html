작품과 권리

작품의 출처를 소중히 여깁니다. 이 안내는 미디어, AI를 활용한 제작, 권리 문제에 대한 처리 원칙을 설명합니다. 모든 미디어의 권리 확인이 끝났다는 보증이나 작품 전체에 대한 포괄적인 재사용 허가는 아닙니다.

출처와 사용 근거AI와 재사용 범위가져오는 미디어권리 문제 알리기확인과 조치법률상 권리템플릿에 관하여문의하기

출처와 사용 근거

개발 과정에서 직접 제작한 아트와 프로그램으로 생성한 표현, AI로 생성하거나 AI의 도움을 받아 제작한 이미지와 동영상, 제3자 미디어를 사용할 수 있습니다. 제3자 미디어를 사용할 때는 범위, 출처 표시, 배포 조건을 포함한 개별 라이선스 또는 다른 적법한 근거를 따라야 합니다. 작가나 출처를 표시하는 것만으로 허가를 받은 것은 아닙니다.

AI와 재사용 범위

인터넷에 공개되어 있거나 AI로 제작되었다는 사실만으로 상업적 사용이 허용되거나 저작권, 초상, 상표 관련 문제가 없어지지는 않습니다. FrameLive에서 이용할 수 있다는 사실 자체가 무제한 재배포나 상업적 재사용을 허가하지는 않습니다. AI 콘텐츠의 저작자 인정과 보호는 구체적인 사실과 적용 법률에 따라 달라집니다. AI 표시나 삭제 약속은 허가나 면책을 대신하지 않습니다.

가져오는 미디어

예정한 편집, 저장, 공유에 필요한 권리를 보유하거나 허가 또는 다른 적법한 사용 근거가 있는 미디어만 가져오세요. 가져온 미디어에 대한 이용자의 책임이 운영자가 제공하는 콘텐츠와 서비스에 대한 법적 의무를 대신하지는 않습니다.

권리 문제 알리기

저작권, 초상 또는 상표 문제가 있다면 작품 ID, 이름 또는 URL과 함께 해당 권리, 본인과의 관계, 문제가 된다고 보는 사용을 설명해 주세요. 이미 공개된 출처 링크나 간단한 권리 근거처럼 안전하게 공개할 수 있는 정보만 제공해 주세요. 신분증, 비공개 원본, 영수증이나 주문 정보는 게시하지 마세요. 공개 Issue에서 이러한 자료를 요구하지 않습니다.

확인과 조치

제공된 정보를 검토합니다. 초기 검토에서 우려에 합리적인 근거가 있으면 추가 확인 중에 전시나 배포를 일시 중단하거나 작품을 내리거나 설명을 수정할 수 있습니다. 근거를 확인하고 관련 당사자의 보충 설명이나 이의를 검토할 기회를 둡니다. 사진 또는 파일 앱에 이미 저장된 사본은 원격으로 회수할 수 없으므로 기기에서 직접 관리해 주세요.

법률상 권리

이 안내는 법률상 권리나 구제 수단, 위법한 고의 행위 또는 중대한 과실로 인한 책임, 그 밖에 적용 법률상 배제하거나 제한할 수 없는 책임을 배제하거나 제한하지 않습니다. 출처 설명이나 삭제 조치만으로 권리 분쟁이 해결되는 것은 아닙니다.

아래 권리 신고 링크에서 공개 GitHub Issue를 작성해 주세요. 제출하려면 GitHub 계정과 로그인이 필요합니다. 현재 비공개 이메일 창구는 제공되지 않으므로 민감한 증거는 공개하지 말고 보관해 주세요. 안전하게 공개할 수 있는 보충 설명이나 이의는 Issue에 추가할 수 있습니다. 이 창구는 법률상 구제 수단을 대신하지 않습니다.

문의하기

질문이나 재현 가능한 문제는 GitHub Issue로 알려 주세요. 제출하려면 GitHub 계정이 필요합니다.

GitHub Issues는 공개됩니다. 개인 사진, Apple 주문 정보, 기기 식별자 등 개인정보를 업로드하지 마세요. 도움을 받기 위해 개인 미디어를 공개할 필요는 없습니다. 문제를 글로 설명하고 민감한 정보는 기기에 보관하세요.

필요할 때, 작은 도움을.

실용적인 답변을 먼저 살펴보세요. 문제가 있다면 상황을 글로 설명해 문의할 수 있습니다.

제작은 무료인가요?

네. 기기 내 제작과 배경화면은 무료입니다. Apple 앱 내 구입으로 자발적인 일회성 후원을 할 수 있지만 콘텐츠나 기능을 잠금 해제하지 않습니다. 구독은 필요하지 않습니다.

배경화면은 어떻게 저장하나요?

작품을 열어 미리 본 뒤 저장 기능을 사용하세요. 요청이 표시되면 사진 앱에 추가를 허용하세요. 거부해도 미리보기와 제작은 가능하며 나중에 iPhone 설정에서 권한을 바꿀 수 있습니다.

잠금 화면이 움직이지 않는 이유는 무엇인가요?

사진 앱에 저장해도 잠금 화면 움직임이 보장되지는 않습니다. 시스템 배경화면 설정에서 해당 작품의 Live 사용 가능 여부를 확인하세요. 동작은 미디어, iPhone, iOS에 따라 달라집니다. 앱 내 재생이나 Live 표시는 깨우기 재생을 확인한 것과 다릅니다.

배경화면이 자동으로 바뀌나요?

아니요. iPhone 시스템 기능에서 직접 고르고 설정하세요. FrameLive는 예약 또는 자동 배경화면 전환을 제공하지 않습니다.

편집에 클라우드 AI를 사용하나요?

아니요. 선택한 동영상은 기기에서 편집되며 원격 AI 생성 서비스로 전송되지 않습니다. 기본 이미지나 동영상 중에는 개발 단계에서 AI로 제작한 것이 있고, 기기 내 규칙으로 생성하는 움직임도 있습니다.

다운로드에 인터넷이 필요한가요?

기본 작품과 기기 내 편집은 배경화면 다운로드 서비스 없이 사용할 수 있습니다. iOS 26 이상에서 추가 작품은 Apple Background Assets로 제공되며 네트워크가 필요할 수 있습니다. 실패하면 연결과 여유 공간을 확인한 뒤 앱에서 다시 시도하세요.

초안과 완성 파일은 어디에 있나요?

제작 화면의 내보낸 작품에서 기기의 완성 작품을 둘러보고 읽기 전용 미리보기를 열 수 있습니다. 삭제하려면 해당 작품의 삭제 기능을 선택하고 명시적으로 확인하세요. 앱 내 완성 작품만 삭제되며 초안이나 사진 또는 파일 앱에 저장한 사본은 삭제되지 않습니다. 사본은 해당 앱에서 관리하세요. 앱을 제거해도 기기 내 앱 파일이 삭제됩니다.

후원 결제 결과가 불분명하면 어떻게 하나요?

결제는 Apple이 처리합니다. 다시 구입할지 결정하기 전에 앱의 구입 상태와 Apple 구입 내역을 확인하세요. 공개 Issue에 영수증이나 Apple 주문 정보를 게시하지 마세요. 후원은 선택 사항이며 제작과 저장의 조건이 아닙니다.

오류 신고에는 무엇이 필요한가요?

진행한 단계, 예상한 결과, 실제 현상, 앱 및 iOS 버전을 글로 알려 주세요. 개인 사진, Apple 주문, 기기 식별자 또는 검토하지 않은 진단 보고서는 포함하지 마세요.

문의하기

질문이나 재현 가능한 문제는 GitHub Issue로 알려 주세요. 제출하려면 GitHub 계정이 필요합니다.

GitHub Issues는 공개됩니다. 개인 사진, Apple 주문 정보, 기기 식별자 등 개인정보를 업로드하지 마세요. 도움을 받기 위해 개인 미디어를 공개할 필요는 없습니다. 문제를 글로 설명하고 민감한 정보는 기기에 보관하세요.

作品與權利

每幅作品的來源都值得認真對待。本說明介紹素材、AI 輔助創作與權利問題的處理原則，不代表全部素材均已完成權利確認，也不構成對作品集的一般再利用授權。

來源與使用依據

開發期間可能使用原創美術與程式生成畫面、AI 生成或輔助製作的圖像與影片，以及第三方素材。使用第三方素材須遵循具體授權或其他合法依據，包括適用範圍、署名和散布條件。標示作者或來源，本身不等於取得授權。

AI 與再利用界線

素材在網路上公開或由 人工智慧 製作，不會自動帶來商用授權，也不會消除著作權、肖像或商標風險。作品在映刻中可用，本身不授予無限制的再散布或商業使用授權。人工智慧 內容的作者認定與保護取決於具體事實及適用法律；人工智慧 標示或「侵權即刪」的承諾都不能取代授權或免除責任。

你匯入的素材

請僅匯入你擁有必要使用權，或已取得授權、具有其他合法使用依據的素材，並涵蓋你計畫進行的編輯、儲存與分享。使用者對匯入素材的責任，不取代營運者對其提供的內容和服務依法承擔的職責。

提出權利問題

如涉及著作權、肖像或商標，請提供作品 ID、名稱或 URL，並說明相關權利、你與該權利的關係及涉嫌不當使用的情況。僅提供可安全公開的資訊，例如既有公開來源連結或簡短的權利依據描述。請勿公開身分證件、私人原圖、收據或訂單；公開 Issue 不要求這些資料。

查核與處理

我們會查核所提供的資訊。初步查核發現問題有合理依據時，可在進一步核驗期間暫停展示或散布、下架作品或更正說明，並保留核驗及相關方補充說明、提出異議的機會。已儲存至「照片」或「檔案」的副本無法遠端撤回，請在自己的裝置上管理。

保留法定權利

本說明不排除或限制法定權利與救濟，不排除或限制違法故意、重大過失所產生的責任，以及適用法律不允許排除或限制的其他責任。來源說明或下架處理本身不代表權利爭議已經解決。

請透過下方權利回報入口提交公開 GitHub Issue，提交需要 GitHub 帳號並登入。目前未提供私人電子郵件管道，請保留敏感憑證，不要公開上傳。你可在 Issue 中補充可安全公開的說明或異議；此管道不取代你依法享有的救濟途徑。

映刻 / FrameLive

需要時，有一點協助。

先看看這些實用解答；遇到問題，也可以用文字描述並聯絡我們。

創作需要付費嗎？

裝置端創作與桌布免費。你可以透過 Apple App 內購買自願提供單次支持，支持不會解鎖內容或功能，也不需要訂閱。

如何儲存桌布？

開啟作品、預覽並使用儲存操作。系統詢問時允許加入「照片」；拒絕後仍可預覽和創作，之後可在 iPhone「設定」中變更權限。

為什麼鎖定畫面沒有動？

儲存到「照片」不保證鎖定畫面動態。請使用系統桌布設定，檢查該作品能否啟用 Live。實際效果取決於素材、iPhone 與 iOS；App 內播放或顯示 Live 標誌，都不等於已驗證喚醒播放。

映刻會自動更換桌布嗎？

不會。請透過 iPhone 系統功能自行選擇和設定桌布，映刻不提供排程或自動更換桌布。

編輯會使用雲端 AI 嗎？

不會。你選擇的影片在裝置上編輯，不會傳送到遠端 AI 生成服務。預設圖像或影片可能在開發階段由 AI 製作，另一類動態效果則由裝置端規則產生。

下載需要網路嗎？

內建作品和裝置端編輯無須桌布下載服務。iOS 26 或更新版本中的更多作品可透過 Apple Background Assets 連網下載。下載失敗時，請檢查網路與可用儲存空間，再使用 App 內重試操作。

草稿和成品檔案在哪裡？

進入「創作 → 已匯出」可瀏覽本機成品並開啟唯讀預覽。刪除本機成品時，請使用對應刪除操作並明確確認。刪除只會移除該 App 內成品，不會刪除其草稿或已儲存至「照片」／「檔案」的副本；這些副本請在對應 App 中管理。移除 App 也會刪除本機 App 檔案。

支持付款結果不明確怎麼辦？

付款由 Apple 處理。請先查看 App 內購買狀態說明與 Apple 購買紀錄，再決定是否再次購買。不要在公開 Issue 上傳收據或 Apple 訂單詳情。支持始終自願，創作和儲存不以支持為條件。

回報問題需要提供什麼？

請描述操作步驟、預期結果、實際現象，以及 App 和 iOS 版本。盡量只用文字，不要提供私人照片、Apple 訂單、裝置識別碼或未經檢查的診斷報告。

聯絡我們

有疑問或可重現的問題，請透過 GitHub Issue 聯絡。提交 Issue 需要 GitHub 帳號。

GitHub Issues 是公開的。請勿上傳私人照片、Apple 訂單詳情、裝置識別碼或其他隱私資料。獲得協助不需要公開私人素材；請用文字描述問題，將敏感資訊保留在自己的裝置上。

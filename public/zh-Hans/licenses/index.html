作品与权利

每幅作品的来源都值得认真对待。本说明介绍素材、AI 辅助创作与权利问题的处理原则，不代表全部素材均已完成清权，也不构成对作品集的一般再使用许可。

来源与使用依据

开发期间可能使用原创美术与程序生成画面、AI 生成或辅助制作的图像与视频，以及第三方素材。使用第三方素材须遵循具体许可或其他合法依据，包括适用范围、署名和分发条件。标注作者或来源，本身不等于获得授权。

AI 与再使用边界

素材在网络上公开或由 人工智能 制作，不会自动带来商用授权，也不会消除著作权、肖像或商标风险。作品在映刻中可用，本身不授予无限制的再分发或商业使用许可。人工智能 内容的作者认定与保护取决于具体事实和适用法律；人工智能 标注或“侵权即删”的承诺都不能替代授权或免除责任。

你导入的素材

请仅导入你拥有必要使用权，或已获得许可、具有其他合法使用依据的素材，并覆盖你计划进行的编辑、保存与分享。用户对导入素材的责任，不替代运营者对其提供的内容和服务依法承担的职责。

提出权利问题

如涉及著作权、肖像或商标，请提供作品 ID、名称或 URL，并说明相关权利、你与该权利的关系及涉嫌不当使用的情况。仅提供可安全公开的信息，例如已有公开来源链接或简短的权利依据描述。请勿公开证件、私人原图、收据或订单；公开 Issue 不要求这些资料。

核查与处理

我们会核查所提供的信息。初步核查发现问题有合理依据时，可在进一步核验期间暂停展示或分发、下架作品或更正说明，并保留核验及相关方补充说明、提出异议的机会。已保存到照片或文件的副本无法远程撤回，请在自己的设备上管理。

保留法定权利

本说明不排除或限制法定权利与救济，不排除或限制违法故意、重大过失所产生的责任，以及适用法律不允许排除或限制的其他责任。来源说明或下架处理本身不代表权利争议已经解决。

请通过下方权利反馈入口提交公开 GitHub Issue，提交需要 GitHub 账号并登录。目前未提供私人邮箱渠道，请保留敏感凭证，不要公开上传。你可在 Issue 中补充可安全公开的说明或异议；此渠道不替代你依法享有的救济途径。
